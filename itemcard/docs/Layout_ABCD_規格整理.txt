FSS Item Card - Layout 規格（討論版）

  本文件僅整理目前已確認的 Layout A～D 規格。
  後續若有修改，以最新討論內容更新。

------------------------------------------------------------------------

共通規格

-   每種 Layout 為獨立規則。
-   Layout 彼此不共用辨識或排版。
-   未來新增 Layout，採新增獨立規則，不修改既有 A～D。
-   Excel 每個訊息只對應一個儲存格。
-   色塊高度固定：150px
-   色塊寬度：依文字內容的實際可見 glyph bounds 自動伸縮
-   左右 Padding：以實際可見 glyph bounds 計算，各 20px
-   各段文字完成定位後，以整組實際可見 glyph bounds 垂直置中色塊。
-   背景色由 Excel 指定，目前支援：
    -   紅：#D0011B
    -   綠：#007661
    -   黃：#FFD200
    -   深藍：#113366
-   字色規則：
    -   黃底固定紅字（#D0011B）
    -   其他底色固定白字（#FFFFFF） （Layout A
        除外，其數字與符號依自身規格。）

------------------------------------------------------------------------

Layout A（單行｜數字放大）

適用

單行文字，數字需強調。

排版

-   固定單行
-   不自動換行

中文

-   字型：ShopeeNotoSans(content)-Medium
-   字級：58pt
-   顏色：#FFFFFF

數字

-   字型：ShopeeNotoSans(content)-Bold
-   字級：62pt
-   顏色：#FFD200

特殊符號（$、%）

-   字型：ShopeeNotoSans(content)-Bold
-   字級：25pt
-   顏色：#FFD200

規則

-   中文正常顯示
-   數字放大
-   $、% 固定縮小
-   $、% 依相鄰數字的實際 ink bottom 動態對齊。
-   Badge 寬度、左右可見留白、超寬驗證與實際繪製使用同一份 Layout A glyph bounds 量測結果。

------------------------------------------------------------------------

Layout B（單行｜全部同字級）

適用

單行文字。

排版

-   固定單行
-   不自動換行

字體

-   字型：ShopeeNotoSans(content)-Medium
-   字級：65pt

字色

-   黃底：#D0011B
-   其他底色：#FFFFFF

規則

-   所有文字皆相同字級。
-   不另外放大數字或縮小符號。
-   依當下單行文字的實際 glyph bounds 動態量測。
-   整組可見文字垂直置中於 150px 色塊，左右可見留白各 20px。

------------------------------------------------------------------------

Layout C（雙行｜左側四字＋右側大數字）

適用

固定格式： - 左側四個中文字 - 右側大數字 - $ 位於數字前 - % 位於數字後

規則

-   Excel 一個儲存格輸入完整文字。
-   Generator 自動辨識。
-   數字前中文字必須固定四個字。
-   自動拆成：
    -   前2字
    -   後2字
-   非四個中文字視為格式不符，不自動猜測拆法。
-   未來若需其他字數，新增新的 Layout，不修改 Layout C。

左側兩行中文

-   字型：ShopeeNotoSans(content)-Medium
-   字級：48.5pt
-   兩行 baseline 距離：50pt
-   顏色：#FFFFFF

右側數字

-   字型：ShopeeNotoSans(content)-Bold
-   字級：110pt
-   顏色：#FFD200

特殊符號（$、%）

-   字型：ShopeeNotoSans(content)-Bold
-   字級：50pt
-   顏色：#FFD200

水平間距

-   左側白字區與第一個數值區元素：10px
-   前置 $ 與數字：5px
-   數字與後置 %：5px

整體排版

-   全部內容排列完成後，以整組實際 glyph bounds 垂直置中於 150px 色塊。
-   左右可見留白各 20px。
-   Badge 寬度、左右可見留白、超寬驗證與實際繪製使用同一份 Layout C glyph bounds 量測結果。

------------------------------------------------------------------------

Layout D（雙行｜Excel 控制換行）

適用

Excel 一個儲存格內以換行區分上下兩行。

例如：

免運 $199起

規則

-   必須且只能有一個換行。
-   Generator 不拆字、不猜測。
-   完全依 Excel 的上下兩行呈現。

第一行

-   字型：ShopeeNotoSans(content)-Regular
-   字級：65pt

第二行

-   字型：ShopeeNotoSans(content)-Regular
-   字級：45pt

若第二行包含 $ 或 % - $、% 字級：30pt

排版

-   第一行與第二行的實際可見 glyph 間距：10px。
-   每次依當下兩行內容的 glyph bounds 動態計算，不使用固定 baseline。
-   前置 $ 依右側相鄰第一個實際可見 glyph 的 ink bottom 動態對齊。
-   後置 % 依左側相鄰最後一個實際可見 glyph 的 ink bottom 動態對齊。
-   兩行與符號完成定位後，以整組實際 glyph bounds 垂直置中於 150px 色塊。
-   左右可見留白各 20px。
-   Badge 寬度依兩行實際可見寬度的最大值自動伸縮。

字色

-   黃底：#D0011B
-   其他底色：#FFFFFF
