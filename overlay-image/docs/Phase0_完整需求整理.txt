==================================================
一、產品定位（Locked）
==================================================

產品名稱：
FSS Item Card 生成器

產品定位：
批次生成器。

主要流程：
匯入 Excel
→ 自動產生全部 Item Card
→ 檢查
→ 必要時微調
→ 下載完整專案

不是完整設計編輯器。
Generator 只提供必要微調，不提供自由設計。

==================================================
二、尺寸與輸出（Locked）
==================================================

設計尺寸：
1200 × 1200 px

預覽尺寸：
只顯示 1200 × 1200 px

最終輸出：
ZIP 壓縮檔

ZIP 內容：
1. 1200 × 1200 PNG
2. 320 × 320 PNG
3. 一個 JSON 暫存檔

DPI：
1200 × 1200：72dpi
320 × 320：72dpi

320 × 320 為 1200 × 1200 自動縮小。
320 × 320 不另外設計版型。

輸出檔名：
直接使用 Excel 的「編號」。

==================================================
三、Badge 共通規格（Locked）
==================================================

一個訊息 = 一個 Badge。
一張 Item Card 最多 3 個 Badge。

Badge 固定規格：
高度：150px
左右 Padding：20px
寬度：依文字內容自動伸縮
全部 Badge 總寬最多：1200px

多個 Badge 左右相連。

排列方向：
由左下開始，依序向右增加。

順序：
第一格 → 第二格 → 第三格

不依顏色、Layout 或文字長度重新排序。
順序完全依目前第一格、第二格、第三格的排列決定。

==================================================
四、顏色規格（Locked）
==================================================

Excel 與 Generator 顯示名稱：
紅
綠
黃
藍

實際色碼：
紅：#D0011B
綠：#007661
黃：#FFD200
藍：#113366

字色規則：
黃底固定紅字：#D0011B
其他底色固定白字：#FFFFFF

Layout A 依 Layout A 自己的字色規則。

==================================================
五、Layout 共通原則（Locked）
==================================================

每種 Layout 都是獨立規則。

Layout 彼此：
不共用辨識。
不共用排版。
不互相自動轉換。
不自動猜測。

未來新增 Layout：
直接新增新的 Layout。
不得修改既有 Layout A～D 的規則。

Excel 每個訊息永遠只使用一個儲存格。

==================================================
六、Layout A（Locked）
==================================================

形式：
單行。

中文：
字型：ShopeeNotoSans(content)-Medium
字級：58pt
顏色：白色 #FFFFFF

數字：
字型：ShopeeNotoSans(content)-Bold
字級：62pt
顏色：黃色 #FFD200

特殊符號：
$
%

字型：ShopeeNotoSans(content)-Bold
字級：25pt
顏色：黃色 #FFD200

規則：
中文正常顯示。
數字放大。
$、% 縮小。
固定單行。
不自動換行。

Generator 右側文字編輯：
顯示一個文字輸入欄。

==================================================
七、Layout B（Locked）
==================================================

形式：
單行。

全部文字：
字型：ShopeeNotoSans(content)-Medium
字級：65pt

字色：
黃底：紅字 #D0011B
其他底色：白字 #FFFFFF

規則：
所有文字相同字級。
不放大數字。
不縮小符號。
固定單行。
不自動換行。

Generator 右側文字編輯：
顯示一個文字輸入欄。

==================================================
八、Layout C（Locked）
==================================================

形式：
雙行。

版面結構：
左側固定四個中文字。
右側為大數字。
$ 固定在數字前。
% 固定在數字後。

Excel 規則：
Excel 只有一個儲存格。
輸入完整文字。
Generator 自動辨識。

中文規則：
數字前的中文字必須固定四個字。

自動拆成：
前兩字
後兩字

若不是四個中文字：
視為格式不符。
不要猜。
不要平均拆。

未來若有其他字數：
新增新的 Layout。
不得修改 Layout C。

Generator 右側文字編輯：
不顯示一個混合文字框。

改為顯示兩個對應欄位：
1. 左側四字
2. 數字＋特殊符號

目的：
讓使用者直接知道內容會顯示在哪個區域。
Generator 不需要在編輯階段再猜拆法。

==================================================
九、Layout D（Locked）
==================================================

形式：
雙行。

Excel 規則：
Excel 同一個儲存格直接換行。
必須且只能有一個換行。

例如：
免運
$199起

Generator 完全依 Excel 換行。
不拆字。
不猜。

第一行：
字型：ShopeeNotoSans(content)-Regular
字級：65pt

第二行：
字型：ShopeeNotoSans(content)-Regular
字級：45pt

第二行若包含：
$
%

符號字級：30pt

字色：
黃底：紅字 #D0011B
其他底色：白字 #FFFFFF

Generator 右側文字編輯：
不顯示一個含換行的混合文字框。

改為顯示兩個對應欄位：
1. 第一行
2. 第二行

目的：
讓使用者直接知道每段文字會顯示在哪一行。
不需要自行維護換行符號。

==================================================
十、Excel 工單（Locked）
==================================================

一列 = 一張 Item Card。

Excel 結構：
編號

第一格
第二格
第三格

每格包含：
文字樣式
顏色
文字內容

欄位名稱維持：
編號
第一格
第二格
第三格

不改成 Item ID、Badge 1 或其他名稱。

原因：
「第幾格」是團隊既有共識。

編號用途：
1. Item Card 識別
2. 輸出檔名

不另外增加輸出檔名欄位。

文字樣式：
使用 Excel 下拉選單。

選項：
A
B
C
D

不開放自行修改下拉選項。

顏色：
使用 Excel 下拉選單。

選項：
紅
綠
黃
藍

不開放自行修改下拉選項。

最多三個 Badge。
不用的格子留白。

不需要 BadgeCount 欄位。
不需要商品名稱、活動名稱、商品代號或其他欄位。

十一、Generator 整體介面（Locked）
==================================================

介面風格：
沿用 FSS 入口平台。

視覺方向：
深色
Liquid Glass
FSS 系列一致風格

版面：
左右兩欄。

左側欄：
響應式。

右側欄：
固定寬度。

==================================================
十二、左側欄－Item Card 預覽（Locked）
==================================================

左側顯示所有 Item Card 預覽。

排列：
桌面寬度足夠時，一行 3 張起。
視窗變窄時，響應式減少欄數。

每張預覽卡：
左上角只顯示編號。
編號不用太大。

點擊 Item Card 時：
1. 預覽卡先微放大。
2. 再回到原本大小。
3. 被選取的預覽卡以重點色外框持續標示。

微放大：
是短暫點擊回饋。

顏色外框：
是持續顯示目前選取哪一張 Item Card。

右側欄同一時間只編輯目前選取的一張 Item Card。

右側欄進行以下修改時：
修改文字
刪除 Badge
新增 Badge
拖曳調整順序

左側目前選取的 Item Card 預覽必須即時更新。

==================================================
十三、右側欄內容（Locked）
==================================================

右側欄固定寬度。

包含：
1. 匯入工單 Excel
2. 匯入暫存檔
3. 目前選取 Item Card 的 Badge 編輯區
4. 下載完整專案
5. 重設工作區域

下載完整專案放在主要操作流程底部。
重設工作區域放在「下載完整專案」下方。

==================================================
十四、Excel 帶入 Badge 的編輯規則（Locked）
==================================================

Excel 帶入的 Badge 可以：
修改文字
拖曳排序
刪除整個 Badge

Excel 帶入的 Badge 不可以：
修改 Layout
修改顏色

Layout 與顏色在右側卡片中顯示為資訊。

呈現方式：
深色卡片
顯示例如「A／紅」
使用純文字顯示

不要把整張右側卡片做成紅、綠、黃、藍背景。

原因：
避免右側欄顏色過多，搶走左側預覽的視覺焦點。

==================================================
十五、新增 Badge（Locked）
==================================================

目前 Item Card 少於 3 個 Badge 時：
允許新增 Badge。

最多仍為 3 個。

新增 Badge 時：
使用者自行選擇：

Layout：A／B／C／D
顏色：紅／綠／黃／藍

選擇 Layout 後：
顯示該 Layout 對應的文字輸入介面。

A：
一個文字輸入欄。

B：
一個文字輸入欄。

C：
左側四字
數字＋特殊符號

D：
第一行
第二行

新增完成後可以：
修改文字
拖曳排序
刪除

新增 Badge 不需要補回原本刪掉的固定位置。
新增後透過拖曳決定實際順序。

==================================================
十六、刪除 Badge（Locked）
==================================================

所有 Badge 都可以整格刪除。

刪除代表：
整個 Badge 移除。

包含：
Layout
顏色
文字

一起移除。

刪除後若總數少於 3：
可以再新增 Badge。

==================================================
十七、Badge 排序（Locked）
==================================================

排序採拖曳。
不用箭頭。

右側每個 Badge 分成獨立區塊。

顯示一行提示：
拖曳調整順序

拖曳對象：
整個 Badge。

包含：
Layout
顏色
文字

一起移動。

排序後由左到右即為：
第一格
第二格
第三格

第一格、第二格、第三格：
代表目前左右位置。
不是 Badge 的永久身份。

==================================================
十八、暫存檔（Locked）
==================================================

暫存檔格式：
JSON

一個 JSON 暫存包含：
全部 Item Card。

不是一張 Item Card 一個 JSON。

暫存檔必須完整保存下載當下工作區的所有內容，包括：

全部 Item Card
每張 Item Card 的編號
每張 Item Card 當下的 Badge 數量
Badge 當下的左右順序
每個 Badge 的 Layout
每個 Badge 的顏色
每個 Badge 的文字內容
Excel 匯入後做過的所有文字修改
刪除的 Badge 結果
新增的 Badge
新增 Badge 的 Layout
新增 Badge 的顏色
新增 Badge 的文字
下載當下目前完整工作狀態

核心原則：
匯入暫存後，工作區必須完整回到下載暫存當下的狀態。

暫存不是只保存原始 Excel。

==================================================
十九、匯入暫存（Locked）
==================================================

匯入暫存檔：
使用 JSON。

匯入後：
完全覆蓋目前工作區。

不與目前資料合併。
不追加 Item Card。
不保留匯入前的修改。

流程：
清除目前工作區
→ 依 JSON 完整還原全部 Item Card
→ 回到暫存檔下載當下的狀態

==================================================
二十、下載完整專案（Locked）
==================================================

下載完整專案：
輸出一個 ZIP 壓縮檔。

ZIP 檔名格式：
ItemCard_MMDD.zip

例如：
ItemCard_0804.zip

ZIP 結構：
ItemCard_0804.zip
│
├── 1200x1200/
│   ├── 編號.png
│   └── …
│
├── 320x320/
│   ├── 編號.png
│   └── …
│
└── ItemCard_0804.json

1200x1200 資料夾：
存放全部 1200 × 1200 PNG。

320x320 資料夾：
存放全部 320 × 320 PNG。

JSON：
保存下載當下的全部工作區狀態。

PNG 檔名：
使用各 Item Card 的編號。

同一天可重複下載。

若發生同名：
由瀏覽器或作業系統依預設方式處理。

==================================================
二十一、重設工作區域（Locked）
==================================================

右側欄「下載完整專案」下方顯示：
重設工作區域

重設後：
清除目前全部 Item Card。
清除所有文字修改。
清除所有 Badge 排序。
清除所有新增 Badge。
清除所有刪除結果。
回到尚未匯入 Excel 或暫存檔的初始狀態。

因為此操作不可逆：
執行前需要一次確認。

確認訊息方向：
確定要重設工作區域嗎？
目前尚未下載的內容將會清除。
